# EBE - Style Guide

## 文体

EBEのpublish記事は、日本語の教科書、参考書、信頼できるレビュー、成書として読める文体で書く。検索結果の寄せ集めや短いメモにしない。

## 必須構成

- タイトル
- 日本語インフォグラフィック
- 引用番号付きキャプション
- 概要
- この記事の見取り図
- 定義と全体像
- 歴史的背景・古典的理解
- 現在の標準的理解
- 詳細説明
- 応用・実践上の含意
- 限界・論争点・未解決事項
- まとめ
- 参考ソース
- 更新履歴
- 更新日付
