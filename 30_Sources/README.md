# 30_Sources

Durable source notes for published or already-published EBE articles.

Temporary source notes, search logs, source candidates, and provisional registries belong under `_working/`. After Publish Gate passes, promote only the final source notes needed to support the published article.

Each source note should record source ID, citation number, title, URL or DOI when available, accessed date, appraisal summary, and claims supported.
